# Полный справочник инструкций Logix 5000
# Каждая инструкция с кратким описанием на русском языке

## БИТОВЫЕ / РЕЛЕЙНЫЕ ИНСТРУКЦИИ

```
XIC  — Examine If Closed (Проверка на замкнутость)
       Проверяет, установлен ли указанный бит в 1. Если да — ранг продолжает выполнение.
       Аналог нормально-открытого контакта в релейной логике.

XIO  — Examine If Open (Проверка на разомкнутость)
       Проверяет, сброшен ли указанный бит в 0. Если да — ранг продолжает выполнение.
       Аналог нормально-закрытого контакта в релейной логике.

OTE  — Output Energize (Включение выхода)
       Устанавливает бит в 1, когда условие ранга истинно, и сбрасывает в 0, когда ложно.
       Аналог катушки реле — состояние отражает текущее состояние ранга.

OTL  — Output Latch (Защёлка выхода)
       Устанавливает бит в 1, когда условие ранга истинно. НЕ сбрасывает при ложном условии.
       Бит остаётся в 1 до тех пор, пока не будет сброшен инструкцией OTU.

OTU  — Output Unlatch (Снятие защёлки)
       Сбрасывает бит в 0, когда условие ранга истинно. Используется в паре с OTL.

ONS  — One Shot (Одноразовый импульс)
       Пропускает выполнение инструкций за ней только один скан при переходе условия
       из ложного в истинное. При следующих сканах блокирует выполнение.

OSR  — One Shot Rising (Одноразовый импульс по переднему фронту)
       Устанавливает выходной бит в 1 на один скан при переходе условия из 0 в 1.
       Использует бит хранения для отслеживания предыдущего состояния.

OSF  — One Shot Falling (Одноразовый импульс по заднему фронту)
       Устанавливает выходной бит в 1 на один скан при переходе условия из 1 в 0.
```

## ТАЙМЕРЫ И СЧЁТЧИКИ

```
TON  — Timer On Delay (Таймер с задержкой включения)
       Начинает отсчёт при истинном условии ранга. Когда аккумулятор достигает
       уставки (PRE), устанавливается бит DN. При ложном условии — сбрасывается.

TOF  — Timer Off Delay (Таймер с задержкой выключения)
       Начинает отсчёт при ЛОЖНОМ условии ранга (после того как был истинным).
       Бит DN остаётся установленным на время задержки после снятия условия.

RTO  — Retentive Timer On (Ретентивный таймер включения)
       Как TON, но аккумулятор НЕ сбрасывается при ложном условии. Значение
       сохраняется между сканами. Сброс — только через инструкцию RES.

TONR — Timer On with Reset (Таймер включения со сбросом, FBD/ST)
       Версия TON для функциональных блоков и структурированного текста.
       Имеет встроенный вход сброса Reset.

TOFR — Timer Off with Reset (Таймер выключения со сбросом, FBD/ST)
       Версия TOF для FBD/ST с входом сброса.

RTOR — Retentive Timer On with Reset (Ретентивный таймер со сбросом, FBD/ST)
       Версия RTO для FBD/ST с входом сброса.

CTU  — Count Up (Счётчик вверх)
       Инкрементирует аккумулятор на 1 при каждом переходе условия из 0 в 1.
       Устанавливает бит DN, когда аккумулятор >= уставки.

CTD  — Count Down (Счётчик вниз)
       Декрементирует аккумулятор на 1 при каждом переходе условия из 0 в 1.
       Устанавливает бит DN, когда аккумулятор >= уставки.

CTUD — Count Up/Down (Счётчик вверх/вниз, FBD/ST)
       Комбинированный счётчик с раздельными входами для счёта вверх и вниз.
       Только для функциональных блоков и структурированного текста.

RES  — Reset (Сброс)
       Сбрасывает аккумулятор таймера или счётчика в 0, а также все биты состояния
       (EN, TT, DN, OV, UN). Применяется к структурам TIMER, COUNTER, CONTROL.
```

## ИНСТРУКЦИИ СРАВНЕНИЯ

```
EQU  — Equal To (Равно)
       Сравнивает два значения. Условие истинно, если source_A = source_B.

NEQ  — Not Equal To (Не равно)
       Условие истинно, если source_A ≠ source_B.

GRT  — Greater Than (Больше)
       Условие истинно, если source_A > source_B.

GEQ  — Greater Than or Equal To (Больше или равно)
       Условие истинно, если source_A >= source_B.

LES  — Less Than (Меньше)
       Условие истинно, если source_A < source_B.

LEQ  — Less Than or Equal To (Меньше или равно)
       Условие истинно, если source_A <= source_B.

LIM  — Limit Test (Проверка диапазона)
       Проверяет, находится ли тестовое значение между нижним и верхним пределами.
       Истинно, если low_limit <= test <= high_limit.

MEQ  — Masked Equal To (Маскированное сравнение)
       Сравнивает source и compare через битовую маску. Истинно, если биты,
       выбранные маской, совпадают.

CMP  — Compare (Сравнение выражением)
       Позволяет задать произвольное выражение сравнения в виде строки.
       Более гибкая, но медленнее EQU/NEQ/GRT и т.д.
```

## МАТЕМАТИЧЕСКИЕ ИНСТРУКЦИИ

```
ADD  — Add (Сложение)
       destination = source_A + source_B.

SUB  — Subtract (Вычитание)
       destination = source_A - source_B.

MUL  — Multiply (Умножение)
       destination = source_A * source_B.

DIV  — Divide (Деление)
       destination = source_A / source_B. Остаток отбрасывается для целых типов.

MOD  — Modulo (Остаток от деления)
       destination = source_A MOD source_B.

NEG  — Negate (Смена знака)
       destination = -source. Меняет знак числа на противоположный.

ABS  — Absolute Value (Модуль числа)
       destination = |source|. Возвращает абсолютное значение.

SQR  — Square Root (Квадратный корень)
       destination = √source.

CPT  — Compute (Вычисление выражения)
       Выполняет произвольное математическое выражение и записывает результат
       в destination. Поддерживает +, -, *, /, **, SIN, COS, TAN, ABS, SQR и др.

XPY  — X to the Power of Y (Возведение в степень)
       destination = source_A ^ source_B.

LN   — Natural Log (Натуральный логарифм)
       destination = ln(source).

LOG  — Log Base 10 (Десятичный логарифм)
       destination = log10(source).

FRD  — Convert from BCD (Конвертация из BCD)
       Преобразует двоично-десятичный код (BCD) в целое число.

TOD  — Convert to BCD (Конвертация в BCD)
       Преобразует целое число в двоично-десятичный код (BCD).

TRN  — Truncate (Усечение)
       Отбрасывает дробную часть REAL и записывает целую часть в destination.

CLR  — Clear (Очистка)
       Устанавливает destination в 0. Для структур обнуляет все поля.
```

## ИНСТРУКЦИИ ПЕРЕМЕЩЕНИЯ И ЛОГИЧЕСКИЕ

```
MOV  — Move (Копирование значения)
       Копирует source в destination. Работает с любыми атомарными типами.

MVM  — Masked Move (Копирование через маску)
       Копирует из source в destination только те биты, которые установлены в маске.
       Биты, не выбранные маской, остаются без изменений в destination.

BTD  — Bit Field Distribute (Распределение битового поля)
       Копирует группу бит из source (начиная с source_bit) в destination
       (начиная с destination_bit) длиной length бит.

SWPB — Swap Byte (Перестановка байтов)
       Меняет порядок байтов в значении. Используется для конвертации Endian-формата
       при обмене данными с устройствами, использующими другой порядок байтов.

AND  — Bitwise AND (Побитовое И)
       destination = source_A AND source_B. Устанавливает бит только там,
       где оба операнда имеют 1.

OR   — Bitwise OR (Побитовое ИЛИ)
       destination = source_A OR source_B. Устанавливает бит, если хотя бы
       один из операндов имеет 1.

XOR  — Bitwise Exclusive OR (Побитовое исключающее ИЛИ)
       destination = source_A XOR source_B. Устанавливает бит только там,
       где биты операндов различаются.

NOT  — Bitwise NOT (Побитовая инверсия)
       destination = NOT source. Инвертирует все биты.
```

## ИНСТРУКЦИИ РАБОТЫ С МАССИВАМИ / ФАЙЛАМИ

```
COP  — Copy (Копирование блока)
       Копирует блок данных из source в destination длиной length элементов.
       НЕ прерывается коммуникационными задачами.

CPS  — Synchronous Copy (Синхронное копирование)
       То же, что COP, но выполняется неделимо (атомарно). Гарантирует,
       что данные не будут изменены другой задачей во время копирования.

FLL  — File Fill (Заполнение массива)
       Заполняет массив destination значением source на length элементов.

AVE  — File Average (Среднее массива)
       Вычисляет среднее арифметическое элементов массива и помещает в destination.

SRT  — File Sort (Сортировка массива)
       Сортирует элементы массива по возрастанию.

STD  — File Standard Deviation (Стандартное отклонение)
       Вычисляет стандартное отклонение элементов массива.

FAL  — File Arithmetic and Logic (Арифметика и логика файлов)
       Выполняет заданное выражение над каждым элементом массива.
       Поддерживает режимы: All (все за скан), Incremental (по одному за скан).

FSC  — File Search and Compare (Поиск и сравнение в файле)
       Ищет в массиве элемент, удовлетворяющий заданному выражению.

SIZE — Size In Elements (Размер массива)
       Возвращает количество элементов в указанном измерении массива.

DDT  — Diagnostic Detect (Диагностическое обнаружение)
       Сравнивает два массива побитово и записывает различия в массив результатов.
       Используется для диагностики — поиск изменившихся бит.

FBC  — File Bit Compare (Побитовое сравнение файлов)
       Сравнивает два массива через маску и находит первое совпадение.
```

## FIFO / LIFO (ОЧЕРЕДИ И СТЕКИ)

```
FFL  — FIFO Load (Загрузка в FIFO-очередь)
       Добавляет значение source в конец FIFO-буфера. Работает по принципу
       «первый вошёл — первый вышел».

FFU  — FIFO Unload (Выгрузка из FIFO-очереди)
       Извлекает первый элемент из FIFO-буфера и помещает в destination.

LFL  — LIFO Load (Загрузка в LIFO-стек)
       Добавляет значение source на вершину LIFO-буфера (стека).

LFU  — LIFO Unload (Выгрузка из LIFO-стека)
       Извлекает верхний элемент из LIFO-буфера (стека) в destination.
       Работает по принципу «последний вошёл — первый вышел».
```

## СДВИГОВЫЕ РЕГИСТРЫ

```
BSL  — Bit Shift Left (Сдвиг бит влево)
       Сдвигает все биты массива на одну позицию влево. Значение source_bit
       загружается в младший бит. Старший бит выгружается в бит UL.

BSR  — Bit Shift Right (Сдвиг бит вправо)
       Сдвигает все биты массива на одну позицию вправо. Значение source_bit
       загружается в старший бит. Младший бит выгружается в бит UL.
```

## СЕКВЕНСОРЫ

```
SQI  — Sequencer Input (Вход секвенсора)
       Сравнивает входные данные с массивом секвенсора через маску.
       Условие истинно, если данные совпадают с текущей позицией.

SQO  — Sequencer Output (Выход секвенсора)
       Записывает значение из текущей позиции массива секвенсора в destination
       через маску. Используется для пошагового управления выходами.

SQL  — Sequencer Load (Загрузка секвенсора)
       Загружает значение source в текущую позицию массива секвенсора.
```

## УПРАВЛЕНИЕ ПРОГРАММОЙ

```
JSR  — Jump to Subroutine (Переход к подпрограмме)
       Вызывает указанную подпрограмму (рутину) с передачей входных параметров
       и получением возвращаемых значений.

SBR  — Subroutine (Начало подпрограммы)
       Помещается в начале вызываемой рутины. Принимает входные параметры от JSR.

RET  — Return (Возврат из подпрограммы)
       Завершает выполнение подпрограммы и возвращает значения в вызывающую рутину.

JMP  — Jump to Label (Безусловный переход)
       Переходит к указанной метке LBL, пропуская все ранги между текущим и меткой.

LBL  — Label (Метка)
       Определяет целевую точку для инструкции JMP.

JXR  — Jump to External Routine (Переход к внешней рутине)
       Вызывает внешнюю рутину (написанную не в Logix), передавая параметры.

FOR  — For Loop (Цикл FOR)
       Многократно вызывает указанную рутину, изменяя индексную переменную
       от начального до конечного значения с заданным шагом.

BRK  — Break (Прерывание цикла FOR)
       Прерывает выполнение цикла FOR и возвращает управление вызывающей рутине.

TND  — Temporary End (Временное завершение)
       Завершает текущий скан рутины. При следующем скане выполнение
       начинается сначала.

MCR  — Master Control Reset (Сброс главного управления)
       Используется парами: первый MCR начинает зону, второй завершает.
       Когда условие ранга с первым MCR ложно, все выходы в зоне сбрасываются.

AFI  — Always False Instruction (Всегда ложная инструкция)
       Всегда возвращает ложное условие. Используется для отключения ранга
       без его удаления.

NOP  — No Operation (Нет операции)
       Ничего не делает. Используется как заглушка или для выравнивания логики.

UID  — User Interrupt Disable (Запрет прерываний)
       Запрещает прерывание текущей задачи более приоритетными задачами.
       Обеспечивает атомарность критических секций кода.

UIE  — User Interrupt Enable (Разрешение прерываний)
       Восстанавливает возможность прерывания задачи. Используется в паре с UID.

EVENT — Trigger Event Task (Запуск событийной задачи)
       Программно запускает указанную событийную задачу (Event Task).

EOT  — End of Transition (Конец перехода SFC)
       Используется в рангах рутины перехода SFC. Устанавливает бит, определяющий
       результат перехода (истина/ложь).
```

## СТРОКОВЫЕ ИНСТРУКЦИИ

```
CONCAT — Concatenate Strings (Конкатенация строк)
         Объединяет строку sourceA со строкой sourceB, результат в destination.

DELETE — Delete String Characters (Удаление символов из строки)
         Удаляет quantity символов из строки source начиная с позиции start.

FIND   — Find String (Поиск подстроки)
         Ищет строку search внутри строки source, начиная с позиции start.
         Возвращает позицию первого вхождения в result.

INSERT — Insert String (Вставка подстроки)
         Вставляет строку sourceB в строку sourceA в позицию start.

MID    — Middle String (Извлечение подстроки)
         Извлекает quantity символов из строки source начиная с позиции start.

UPPER  — Convert to Upper Case (Преобразование в верхний регистр)
         Преобразует все символы строки source в заглавные.

LOWER  — Convert to Lower Case (Преобразование в нижний регистр)
         Преобразует все символы строки source в строчные.

DTOS   — DINT to String (Целое число в строку)
         Преобразует целое число (DINT) в строковое представление.

STOD   — String to DINT (Строка в целое число)
         Преобразует строковое представление числа обратно в DINT.

RTOS   — REAL to String (Вещественное число в строку)
         Преобразует вещественное число (REAL) в строковое представление.

STOR   — String to REAL (Строка в вещественное число)
         Преобразует строковое представление числа в REAL.
```

## КОММУНИКАЦИИ

```
MSG  — Message (Сообщение)
       Отправляет / принимает данные от удалённого устройства. Поддерживает
       CIP, DH+, блочные передачи, чтение/запись таблиц PLC-2/3/5/SLC.
       Работает асинхронно — не блокирует скан.

GSV  — Get System Value (Чтение системного значения)
       Читает атрибут системного объекта контроллера (Task, Module, Controller и др.)
       Например: получить время задачи, серийный номер, состояние модуля.

SSV  — Set System Value (Запись системного значения)
       Записывает значение в атрибут системного объекта контроллера.
       Например: изменить период задачи, установить флаг.

IOT  — Immediate Output (Немедленный вывод)
       Немедленно обновляет выходные данные указанного тега (модуля),
       не дожидаясь конца скана. Используется для критичных по времени выходов.
```

## ДИАГНОСТИКА

```
DTR  — Data Transition (Обнаружение изменения данных)
       Сравнивает source с reference через маску. Если биты отличаются — условие
       истинно, и reference обновляется. Используется для обнаружения изменений.
```

## ПИД-РЕГУЛИРОВАНИЕ

```
PID  — Proportional Integral Derivative (ПИД-регулятор)
       Классический ПИД-регулятор для замкнутых контуров управления.
       Входы: PV (process variable), уставка, tieback, управляющий выход.
       Поддерживает автонастройку и переключение ручной/авто.

PIDE — Enhanced PID (Расширенный ПИД, FBD/ST)
       Улучшенная версия PID для FBD и ST. Поддерживает каскадное управление,
       режимы (авто/ручной/каскад/соотношение), антивозгонку (anti-windup),
       встроенные аварии по уровням (HH/H/L/LL) и скорости изменения.
```

## АВАРИЙНЫЕ ИНСТРУКЦИИ

```
ALMA — Analog Alarm (Аналоговая авария)
       Мониторит аналоговый вход на превышение уровней: HH, H, L, LL,
       а также скорость изменения (ROC+ / ROC-). Поддерживает квитирование,
       подавление, блокировку, отсрочку (shelving). Сообщения для HMI.

ALMD — Digital Alarm (Дискретная авария)
       Мониторит дискретный (BOOL) вход на аварийное состояние.
       Поддерживает квитирование, защёлку (latch), подавление, блокировку.

ALM  — Alarm (Авария, FBD)
       Версия аварийной инструкции для FBD. Мониторит аналоговый вход
       по уровням HH/H/L/LL и скорости изменения.
```

## ПОСЛЕДОВАТЕЛЬНЫЙ ПОРТ (ASCII)

```
ABL  — ASCII Test Buffer for Line (Проверка строки в буфере)
       Проверяет, есть ли полная строка (заканчивающаяся символом терминатора)
       во входном буфере последовательного порта.

ACB  — ASCII Chars in Buffer (Символы в буфере)
       Возвращает количество символов, находящихся во входном буфере
       последовательного порта.

ACL  — ASCII Clear Buffer (Очистка буфера)
       Очищает входной и/или выходной буфер последовательного порта.

AHL  — ASCII Handshake Lines (Линии квитирования)
       Позволяет читать и устанавливать линии управления (DTR, RTS)
       последовательного порта через битовые маски AND и OR.

ARD  — ASCII Read (Чтение ASCII)
       Читает указанное количество символов из входного буфера последовательного порта.

ARL  — ASCII Read Line (Чтение строки ASCII)
       Читает символы из буфера до символа терминатора (конца строки).

AWA  — ASCII Write Append (Запись с добавлением)
       Записывает строку в последовательный порт и добавляет символы
       завершения (carriage return, line feed и т.д.).

AWT  — ASCII Write (Запись ASCII)
       Записывает строку в последовательный порт без добавления символов завершения.
```

## ИНСТРУКЦИИ ПРОЦЕССНОГО УПРАВЛЕНИЯ (FBD/ST)

```
BAND — Boolean AND (Логическое И, FBD)
       Выполняет логическое И над 4 входами. Выход = In1 AND In2 AND In3 AND In4.

BNOT — Boolean NOT (Логическое НЕ, FBD)
       Инвертирует один логический вход. Выход = NOT In.

BOR  — Boolean OR (Логическое ИЛИ, FBD)
       Выполняет логическое ИЛИ над 4 входами. Выход = In1 OR In2 OR In3 OR In4.

BXOR — Boolean Exclusive OR (Исключающее ИЛИ, FBD)
       Выполняет XOR над двумя логическими входами.

D2SD — Discrete 2-State Device (Дискретное 2-позиционное устройство)
       Управляет 2-позиционным устройством (клапан открыт/закрыт, мотор вкл/выкл).
       Поддерживает режимы: программный, операторский, ручной, override.
       Контролирует обратную связь от концевиков.

D3SD — Discrete 3-State Device (Дискретное 3-позиционное устройство)
       Управляет 3-позиционным устройством (например, клапан: открыт/промежуток/закрыт).
       Три выхода, три входа обратной связи, режимы управления.

DEDT — Deadtime (Мёртвое время / задержка)
       Задерживает входной сигнал на указанное время. Используется для компенсации
       транспортной задержки в контурах регулирования.

DERV — Derivative (Дифференциальное звено)
       Вычисляет производную входного сигнала по времени. Используется
       в контурах управления для опережающей коррекции.

DFF  — D Flip-Flop (D-триггер)
       Цифровой D-триггер: при переднем фронте Clock выход Q = вход D.
       Вход Clear сбрасывает выход. Есть инвертированный выход QNot.

ESEL — Enhanced Select (Расширенный селектор)
       Выбирает один из 6 входов на основе заданного селектора.
       Поддерживает режимы: программный, операторский, override.

FGEN — Function Generator (Генератор функции)
       Кусочно-линейная аппроксимация: по массивам X и Y точек строит
       произвольную функцию. Интерполирует между заданными точками.

HLL  — High/Low Limiter (Ограничитель верх/низ)
       Ограничивает выходное значение заданными верхним и нижним пределами.
       Формирует аварии при достижении пределов.

HPF  — High Pass Filter (Фильтр верхних частот)
       Пропускает быстро изменяющиеся компоненты сигнала, подавляя
       медленные (постоянную составляющую). Цифровой фильтр 1-го порядка.

INTG — Integrator (Интегратор)
       Вычисляет интеграл входного сигнала по времени. Поддерживает
       ограничение выхода и инициализацию.

JKFF — JK Flip-Flop (JK-триггер)
       Цифровой JK-триггер с входами J, K, Clock и Clear.
       Вход Clear сбрасывает выход. Есть инвертированный выход QNot.

LDL2 — Lead-Lag 2nd Order (Опережение-запаздывание 2-го порядка)
       Фильтр опережения-запаздывания второго порядка. Используется
       для компенсации динамики в контурах управления.

LDLG — Lead-Lag (Опережение-запаздывание)
       Фильтр опережения-запаздывания первого порядка. Корректирует
       фазовую характеристику в контурах регулирования.

LPF  — Low Pass Filter (Фильтр нижних частот)
       Пропускает медленно изменяющиеся компоненты сигнала, подавляя
       шумы и высокочастотные помехи. Цифровой фильтр 1-го порядка.

MAVE — Moving Average (Скользящее среднее)
       Вычисляет скользящее среднее входного сигнала по заданному
       количеству отсчётов. Сглаживает шумы.

MAXC — Maximum Capture (Захват максимума)
       Отслеживает и запоминает максимальное значение входного сигнала.
       Можно сбросить вручную через вход Reset.

MINC — Minimum Capture (Захват минимума)
       Отслеживает и запоминает минимальное значение входного сигнала.

MSTD — Moving Standard Deviation (Скользящее стандартное отклонение)
       Вычисляет стандартное отклонение входного сигнала по скользящему
       окну заданного размера.

MUX  — Multiplexer (Мультиплексор)
       Выбирает один из 8 входов на основе целочисленного селектора.
       Выход = In[Selector].

MVMT — Masked Move with Target (Маскированное перемещение с целью)
       Копирует биты из source в target через маску. Где маска = 0,
       сохраняется значение из target (а не destination).

NTCH — Notch Filter (Режекторный фильтр)
       Подавляет сигнал на определённой частоте (узкополосный фильтр).
       Используется для удаления конкретной частоты помехи.

OSFI — One Shot Falling Input (Одноразовый импульс по спаду, FBD)
       FBD-версия: генерирует одноразовый импульс на один скан при
       переходе входа из 1 в 0.

OSRI — One Shot Rising Input (Одноразовый импульс по нарастанию, FBD)
       FBD-версия: генерирует одноразовый импульс на один скан при
       переходе входа из 0 в 1.

PI   — Proportional + Integral (ПИ-регулятор)
       Простой ПИ-регулятор (без дифференциальной составляющей).
       Подходит для контуров, где дифференциальное действие не нужно.

PMUL — Pulse Multiplier (Умножитель импульсов)
       Генерирует выходные импульсы с частотой, пропорциональной входному сигналу.
       Используется для управления шаговыми клапанами.

POSP — Position Proportional (Позиционный пропорциональный регулятор)
       Управляет позиционным клапаном. Формирует сигналы «Открыть»/«Закрыть»
       на основе разницы между уставкой (SP) и текущей позицией.

RESD — Reset Dominant (Триггер с доминантным сбросом)
       SR-триггер, у которого Reset имеет приоритет над Set.
       Если оба активны — выход сбрасывается.

RLIM — Rate Limiter (Ограничитель скорости изменения)
       Ограничивает скорость изменения выходного сигнала. Вход ByPass
       позволяет пропустить без ограничения.

RMPS — Ramp/Soak (Нагрев/выдержка)
       Выполняет программу рампа/выдержка: последовательно нагревает
       до целевых значений и выдерживает заданное время на каждом уровне.

SCL  — Scale (Масштабирование)
       Линейное масштабирование входного значения. Преобразует из одного
       диапазона в другой (например, 4-20 мА в 0-100%).

SCRV — S-Curve (S-кривая)
       Генерирует S-образную кривую для плавного разгона/торможения.

SEL  — Select (Селектор)
       Выбирает один из двух входов на основе селектора.
       Если SelectorIn = 0, выход = In1. Если = 1, выход = In2.

SETD — Set Dominant (Триггер с доминантной установкой)
       SR-триггер, у которого Set имеет приоритет над Reset.
       Если оба активны — выход устанавливается.

SNEG — Selectable Negate (Выборочная инверсия знака)
       Если NegateEnable = 1, выход = -вход. Если 0, выход = вход.

SOC  — Second Order Controller (Регулятор 2-го порядка)
       Контроллер второго порядка для сложных контуров регулирования.

SRTP — Split Range Time Proportional (Разделение диапазона с ШИМ)
       Разделяет управляющий сигнал на нагрев/охлаждение и преобразует
       в широтно-импульсную модуляцию (ШИМ).

SSUM — Selected Summer (Выборочный сумматор)
       Суммирует до 4 входов, каждый с индивидуальным переключателем включения.

TOT  — Totalizer (Тотализатор / Интегратор потока)
       Накапливает интеграл входного сигнала по времени. Используется для
       подсчёта расхода (например, литры за период). Поддерживает старт/стоп/сброс.

UPDN — Up/Down Accumulator (Счётчик вверх/вниз, FBD)
       Аналоговый аккумулятор: складывает InPlus, вычитает InMinus.

BTDT — Bit Field Distribute with Target (Распределение бит с целью, FBD)
       FBD-версия BTD с дополнительным входом Target для определения
       неизменяемых бит.
```

## УПРАВЛЕНИЕ SFC (ПОСЛЕДОВАТЕЛЬНЫЕ ФУНКЦИОНАЛЬНЫЕ СХЕМЫ)

```
SFP  — SFC Pause (Приостановка SFC)
       Приостанавливает или возобновляет выполнение указанной SFC-рутины.
       target_state: Running, Paused.

SFR  — SFC Reset (Сброс SFC)
       Сбрасывает SFC-рутину и устанавливает выполнение на указанный шаг.

PSC  — Pause SFC (Пауза текущей SFC)

PFL  — Pause for Fault Log (Пауза для записи ошибки)

PPD  — Pause Phase Delay (Пауза фазы с задержкой)
       Приостанавливает текущую фазу SFC, давая время для завершения операций.

PRNP — Pause Run Next Phase (Пауза до запуска следующей фазы)
       Приостанавливает текущую фазу до тех пор, пока не будет запущена следующая.
```

```
PATT — Phase Attach (Присоединение к фазе)

       Позволяет управлять фазой из внешней программы.

PCMD — Phase Command (Команда фазе)

PCLF — Phase Clear Failure (Очистка ошибки фазы)

PDET — Phase Detach (Отсоединение от фазы)

PXRQ — Phase External Request (Внешний запрос фазы)
       Генерирует внешний запрос от фазы (например, запрос к внешнему
       секвенсору, такому как FactoryTalk Batch).
```

## ИНСТРУКЦИИ УПРАВЛЕНИЯ ДВИЖЕНИЕМ (MOTION)

```
MSO  — Motion Servo On (Включение сервопривода)
       Включает серводвигатель оси. Подаёт напряжение на усилитель.

MSF  — Motion Servo Off (Выключение сервопривода)
       Выключает серводвигатель оси. Снимает напряжение с усилителя.

MAH  — Motion Axis Home (Позиционирование оси на «домой»)
       Запускает процедуру поиска начальной точки (home) для оси.
       Режимы: Active, Passive, Absolute.

MAJ  — Motion Axis Jog (Толчковое перемещение оси)
       Запускает непрерывное движение оси с заданной скоростью и направлением.
       Ось движется, пока не будет остановлена.

MAM  — Motion Axis Move (Перемещение оси)
       Перемещает ось на заданную позицию или на заданное расстояние.
       Типы: Absolute (в позицию), Incremental (на расстояние).

MAS  — Motion Axis Stop (Остановка оси)
       Останавливает движение оси. Типы: Immediate (мгновенно),
       Fast Stop (быстро), Controlled (с торможением по профилю).

MASD — Motion Axis Shutdown (Аварийное отключение оси)
       Выполняет аварийное отключение оси — снимает управление и обесточивает.

MASR — Motion Axis Shutdown Reset (Сброс аварийного отключения)
       Сбрасывает состояние аварийного отключения оси. Переводит ось
       из состояния Shutdown обратно в Axis Ready.

MAG  — Motion Axis Gear (Электронный редуктор)
       Создаёт электронную связь «ведущий-ведомый» между двумя осями.
       Ведомая ось движется пропорционально ведущей с заданным соотношением.

MAPC — Motion Axis Position Cam (Позиционный кулачок)
       Создаёт связь по позиционному кулачковому профилю между ведущей
       и ведомой осями. Профиль задаётся массивом точек.

MATC — Motion Axis Time Cam (Временной кулачок)
       Создаёт связь по временному кулачковому профилю. Ведомая ось
       следует профилю, привязанному ко времени, а не к позиции ведущей оси.

MAR  — Motion Axis Registration (Регистрация оси)
       Захватывает позицию оси по внешнему событию (триггеру).
       Используется для точной синхронизации с внешними датчиками.

MAW  — Motion Axis Watch Position (Наблюдение за позицией оси)
       Ожидает достижения осью заданной позиции и генерирует событие.

MAOC — Motion Axis Output Cam (Выходной кулачок)
       Управляет цифровым выходом привода на основе кулачкового профиля,
       привязанного к позиции оси.

MDOC — Motion Disarm Output Cam (Отключение выходного кулачка)
       Отключает ранее активированный выходной кулачок.

MCD  — Motion Change Dynamics (Изменение динамических параметров)
       Изменяет скорость, ускорение, замедление оси во время движения.

MRP  — Motion Redefine Position (Переопределение позиции)
       Переопределяет текущую позицию оси без физического перемещения.

MDO  — Motion Direct Drive Output (Прямое управление выходом)
       Подаёт напряжение/ток напрямую на привод, минуя контуры управления.

MDF  — Motion Direct Drive Off (Отключение прямого управления)
       Выключает режим прямого управления выходом.

MDR  — Motion Direct Drive On (Включение прямого управления)
       Включает режим прямого управления выходом.

MDW  — Motion Dwell (Пауза движения)
       Останавливает ось на указанное время, удерживая позицию.

MGS  — Motion Group Stop (Остановка группы осей)
       Останавливает все оси в группе движения.

MGSD — Motion Group Shutdown (Аварийное отключение группы)
       Аварийно отключает все оси в группе движения.

MGSP — Motion Group Strobe Position (Фиксация позиции группы)
       Одновременно захватывает (фиксирует) текущие позиции всех осей
       в группе. Используется для согласованного чтения позиций.

MGSR — Motion Group Shutdown Reset (Сброс отключения группы)
       Сбрасывает состояние аварийного отключения для всех осей в группе.

MAAT — Motion Apply Axis Tuning (Применение настройки оси)
       Применяет рассчитанные параметры настройки (gains) к сервоконтуру оси.

MAFR — Motion Apply Frequency Response (Применение частотной характеристики)
       Применяет данные частотного анализа для настройки оси.

MAHD — Motion Axis Hookup Diagnostics (Диагностика подключения оси)
       Запускает диагностический тест для проверки правильности подключения
       обратной связи и направления движения оси.

MRHD — Motion Run Hookup Diagnostics (Выполнение диагностики подключения)
       Запускает полный цикл диагностики подключения оси.

MRAT — Motion Run Axis Tuning (Запуск автонастройки оси)
       Запускает процедуру автоматической настройки (autotuning) сервоконтура оси.

MCCD — Motion Coordinated Change Dynamics (Изменение динамики координатного движения)
       Изменяет скорость/ускорение/замедление координированного движения на лету.

MCCM — Motion Coordinated Circular Move (Координированное круговое перемещение)
       Выполняет круговое или дуговое перемещение в координатной системе.

MCCP — Motion Calculate Cam Profile (Расчёт кулачкового профиля)
       Рассчитывает кулачковый профиль по заданным точкам.

MCLM — Motion Coordinated Linear Move (Координированное линейное перемещение)
       Выполняет прямолинейное перемещение в координатной системе.

MCS  — Motion Coordinated Stop (Координированная остановка)
       Останавливает координированное движение всех осей в координатной системе.

MCSD — Motion Coordinated Shutdown (Аварийное отключение координатной системы)
       Аварийно отключает все оси координатной системы.

MCSR — Motion Coordinated Shutdown Reset (Сброс координированного отключения)
       Сбрасывает состояние отключения для координатной системы.

MCSV — Motion Calculate Slave Values (Расчёт значений ведомой оси)
       Рассчитывает значения позиции, скорости, ускорения ведомой оси
       по кулачковому профилю для заданной позиции ведущей оси.

MCT  — Motion Coordinated Transform (Координатная трансформация)
       Выполняет трансформацию координат между двумя координатными системами.
       Например, из декартовой системы робота в систему осей.

MCTP — Motion Calculate Transform Position (Расчёт позиции трансформации)
       Рассчитывает позицию в целевой координатной системе на основе
       позиции в исходной системе и параметров трансформации.

MCR  — Master Control Reset (Сброс главного управления)
       В контексте Ladder: обрамляет зону ранг, при ложном условии все выходы
       внутри зоны обнуляются. Не путать с Motion-инструкциями.
```

## ИНСТРУКЦИИ БЕЗОПАСНОСТИ (SAFETY)

```
DCM  — Dual Channel Input Monitor (Мониторинг двухканального входа)
       Контролирует два входных канала на согласованность. Если каналы
       расходятся дольше допустимого времени — формируется аварийный выход.

DCS  — Dual Channel Stop (Двухканальная остановка)
       Контролирует два входных канала и формирует безопасный выход останова.
       Поддерживает типы перезапуска: автоматический, ручной.

DCSRT — Dual Channel Stop with Run/Test (Двухканальная остановка с режимом Пуск/Тест)
       Как DCS, но с дополнительным входом Enable для переключения
       между режимами работы и тестирования.

DCST — Dual Channel Stop with Test (Двухканальная остановка с тестом)
       Как DCS, но с входом запроса тестирования для периодической
       проверки работоспособности системы безопасности.

DCSTM — Dual Channel Stop with Test and Mute (С тестом и подавлением)
       Расширение DCST с поддержкой мьютинга (подавления) — позволяет
       временно отключить защиту при проходе через зону безопасности.

DCSTL — Dual Channel Stop with Test and Lock (С тестом и блокировкой)
       Расширение DCST с поддержкой блокировки — для процедур LOTO
       (Lockout/Tagout) при обслуживании оборудования.

DIN  — Dual Input (Двойной вход)
       Мониторинг двух входных каналов с проверкой согласованности.
       Поддерживает сброс цепи и сброс ошибки.

ENPEN — Enable Pendant (Разрешение подвесного пульта)
       Контролирует двухканальный вход кнопки Enable на подвесном пульте управления.

ESTOP — Emergency Stop (Аварийная остановка)
       Обрабатывает двухканальный вход кнопки аварийной остановки (E-STOP).
       Поддерживает различные типы перезапуска.

LC   — Light Curtain (Световая завеса)
       Контролирует двухканальный вход световой завесы. Поддерживает мьютинг
       (подавление при контролируемом проходе) и фильтрацию входа.

RIN  — Redundant Input (Резервированный вход)
       Мониторинг двух резервированных входных каналов с проверкой согласованности.

ROUT — Redundant Output (Резервированный выход)
       Управляет двумя резервированными выходными каналами с контролем
       обратной связи.

SMAT — Safety Mat (Защитный коврик)
       Контролирует двухканальный вход защитного коврика безопасности.
       Обнаруживает короткое замыкание проводов.

THRS — Two-Hand Run Station (Двуручный пульт управления)
       Контролирует две кнопки двуручного пульта. Выход активируется
       только при одновременном нажатии обеих кнопок.

THRSE — Two-Hand Run Station with Enable (Двуручный пульт с разрешением)
       Расширение THRS с дополнительным входом разрешения Enable
       и контролем рассогласования между кнопками.

EPMS — Eight-Point Mute Sensor (8-точечный датчик мьютинга)
       Контролирует до 8 датчиков мьютинга с блокировкой.
       Используется для сложных зон безопасности с множеством датчиков.

FPMS — Five-Point Mute Sensor (5-точечный датчик мьютинга)
       Контролирует до 5 датчиков мьютинга с проверкой ошибок.

FSBM — Four-Sensor Bidirectional Mute (4-датчиковый двунаправленный мьютинг)
       Управляет мьютингом световой завесы с 4 датчиками, определяющими
       направление движения объекта через защитную зону.

TSAM — Two-Sensor Asymmetric Mute (2-датчиковый асимметричный мьютинг)
       Управляет мьютингом с 2 датчиками для однонаправленного прохода.

TSSM — Two-Sensor Symmetric Mute (2-датчиковый симметричный мьютинг)
       Управляет мьютингом с 2 датчиками для двунаправленного прохода.
       Датчики расположены симметрично относительно завесы.

CSM  — Configurable Safety Module (Настраиваемый модуль безопасности)
       Универсальный блок безопасности. Мониторит два канала, контролирует
       механическую задержку и максимальный период импульса.
```

## ИНСТРУКЦИИ УПРАВЛЕНИЯ ПРЕССОМ (SAFETY)

```
AVC  — Anti-Repeat Valve Control (Управление клапаном с защитой от повторного хода)
       Управляет клапаном пресса с контролем обратной связи, предотвращая
       повторный ход при заклинивании клапана.

CBCM — Continuous Barrier Control Module (Модуль непрерывного барьерного управления)
       Управление прессом в непрерывном режиме работы с контролем
       барьерной защиты и мониторингом зоны скольжения.

CBIM — Continuous Barrier Inch Module (Модуль барьерного толчкового управления)
       Управление толчковым (дюймовым) режимом пресса с барьерной защитой
       и контролем времени толчка.

CBSSM — Continuous Barrier Single Stroke Module (Модуль барьерного одноходового управления)
       Управление одноходовым режимом пресса с барьерной защитой.

CPM  — Cam Press Monitor (Мониторинг кулачкового пресса)
       Контролирует положение ползуна кулачкового пресса по кулачковому профилю.
       Поддерживает тормозной, обгонный и динамический кулачки.

CROUT — Configurable Redundant Output (Настраиваемый резервированный выход)
       Управляет резервированным (двухканальным) выходом безопасности
       с контролем обратной связи и настраиваемым временем реакции.

MMVC — Mechanical Motion Valve Control (Механическое управление клапаном движения)
       Контролирует механический клапан пресса. Проверяет Enable, переключатель
       режима, конечные выключатели и останов маховика.

MVC  — Motion Valve Control (Управление клапаном движения)
       Управляет клапаном пресса с контролем двух каналов обратной связи
       и настраиваемым временем реакции.
```

## ПОЛЬЗОВАТЕЛЬСКИЕ БЛОКИ (AOI)

```
AOI_SEQUENCE — Custom Sequence Controller (Контроллер пользовательской последовательности)
               Пользовательский блок (Add-On Instruction) для пошагового управления процессом.
               Он хранит номер текущего шага, проверяет условия перехода и управляет таймерами
               или командами для каждого этапа последовательности.
```
