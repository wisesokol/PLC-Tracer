# Полный справочник инструкций Allen-Bradley SLC 500
# Каждая инструкция с кратким описанием на русском языке
# Источник: Publication 1747-RM001G-EN-P (SLC 500 Instruction Set Reference Manual)
# Процессоры: SLC 500, SLC 5/01, SLC 5/02, SLC 5/03, SLC 5/04, SLC 5/05

## БИТОВЫЕ / РЕЛЕЙНЫЕ ИНСТРУКЦИИ

```
XIC  — Examine If Closed (Проверка на замкнутость)
       Проверяет, установлен ли указанный бит в 1. Если да — ранг продолжает выполнение.
       Аналог нормально-открытого контакта в релейной логике.
       Адресация: B3:0/0, I:1/0, O:0/0 и др.

XIO  — Examine If Open (Проверка на разомкнутость)
       Проверяет, сброшен ли указанный бит в 0. Если да — ранг продолжает выполнение.
       Аналог нормально-закрытого контакта в релейной логике.

OTE  — Output Energize (Включение выхода)
       Устанавливает бит в 1 при истинном условии ранга, сбрасывает в 0 при ложном.
       Аналог катушки реле — состояние зеркально повторяет состояние ранга.
       Не использовать один и тот же адрес OTE в нескольких рангах.

OTL  — Output Latch (Защёлка выхода)
       Устанавливает бит в 1 при истинном условии ранга. НЕ сбрасывает при ложном.
       Бит остаётся в 1 до явного сброса инструкцией OTU. Ретентивный выход.

OTU  — Output Unlatch (Снятие защёлки)
       Сбрасывает бит в 0 при истинном условии ранга. Используется в паре с OTL.
       OTL и OTU должны использовать один и тот же адрес бита.

OSR  — One Shot Rising (Одноразовый импульс по переднему фронту)
       Устанавливает выходной бит в 1 на один скан при переходе условия ранга
       из 0 в 1 (передний фронт). Использует бит хранения для отслеживания
       предыдущего состояния. Доступен начиная с SLC 5/02.
```

## ТАЙМЕРЫ

```
TON  — Timer On Delay (Таймер с задержкой включения)
       Начинает отсчёт при истинном условии ранга. Когда ACC >= PRE, 
       устанавливается бит DN. При ложном условии ACC сбрасывается в 0.
       Адрес: T4:n. Элементы: .PRE (уставка), .ACC (аккумулятор).
       Биты: .EN (разрешён), .TT (идёт отсчёт), .DN (выполнен).
       База времени: 1.0 с или 0.01 с.

TOF  — Timer Off Delay (Таймер с задержкой выключения)
       Начинает отсчёт при переходе условия из истинного в ложное.
       Бит DN устанавливается, когда условие истинно, и остаётся
       установленным на время задержки после снятия условия.
       При ложном условии отсчитывает время, затем сбрасывает DN.

RTO  — Retentive Timer On (Ретентивный таймер включения)
       Как TON, но аккумулятор НЕ сбрасывается при ложном условии.
       Значение ACC сохраняется между сканами. Может накапливать время
       от нескольких включений. Сброс — только через инструкцию RES.
```

## СЧЁТЧИКИ

```
CTU  — Count Up (Счётчик вверх)
       Инкрементирует ACC на 1 при каждом переходе условия из 0 в 1.
       Устанавливает DN при ACC >= PRE. При ACC > +32767 устанавливает OV.
       Адрес: C5:n. Элементы: .PRE, .ACC. Биты: .CU, .DN, .OV, .UN.

CTD  — Count Down (Счётчик вниз)
       Декрементирует ACC на 1 при каждом переходе условия из 0 в 1.
       Устанавливает DN при ACC >= PRE. При ACC < -32768 устанавливает UN.

HSC  — High-Speed Counter (Высокоскоростной счётчик)
       Аппаратный счётчик, работающий асинхронно к скану программы.
       Считает внешние импульсы с частотой до нескольких кГц.
       Только для фиксированных контроллеров SLC 500. Адрес: C5:0.
       Требуется перерезать перемычку J2 на плате контроллера.

RES  — Reset (Сброс)
       Сбрасывает ACC в 0 и все биты состояния (EN, TT, DN, OV, UN) 
       для таймеров (T4:), счётчиков (C5:) и управляющих структур (R6:).
```

## ИНСТРУКЦИИ СРАВНЕНИЯ

```
EQU  — Equal (Равно)
       Условие истинно, если source_A = source_B.
       Типы: integer (N7:), float (F8:).

NEQ  — Not Equal (Не равно)
       Условие истинно, если source_A ≠ source_B.

LES  — Less Than (Меньше)
       Условие истинно, если source_A < source_B.

LEQ  — Less Than or Equal (Меньше или равно)
       Условие истинно, если source_A <= source_B.

GRT  — Greater Than (Больше)
       Условие истинно, если source_A > source_B.

GEQ  — Greater Than or Equal (Больше или равно)
       Условие истинно, если source_A >= source_B.

MEQ  — Masked Comparison for Equal (Маскированное сравнение)
       Сравнивает source и compare через битовую маску.
       Истинно, если совпадают биты, выбранные маской.
       Маска может быть константой или адресом слова.

LIM  — Limit Test (Проверка диапазона)
       Проверяет, находится ли тестовое значение в заданном диапазоне.
       Истинно, если low_limit <= test <= high_limit.
       Если low_limit > high_limit — проверка инвертируется.
```

## МАТЕМАТИЧЕСКИЕ ИНСТРУКЦИИ

```
ADD  — Add (Сложение)
       dest = source_A + source_B. Обновляет биты S:0 (carry, overflow, zero, sign).

SUB  — Subtract (Вычитание)
       dest = source_A - source_B.

MUL  — Multiply (Умножение)
       dest = source_A × source_B. Полный результат 32 бита в math register S:13-S:14.

DIV  — Divide (Деление)
       dest = source_A / source_B. Остаток хранится в math register S:14.
       Деление на 0 вызывает minor fault (ошибка 0020h).

DDV  — Double Divide (Двойное деление)
       Делит 32-битное значение из math register (S:13-S:14) на source.
       Используется после MUL для расширенной точности.

CLR  — Clear (Очистка)
       Устанавливает dest в 0. Работает с integer и float типами.

SQR  — Square Root (Квадратный корень)
       dest = √source. Для integer — усекает дробную часть.

NEG  — Negate (Смена знака)
       dest = -source. Меняет знак числа на противоположный.

ABS  — Absolute Value (Модуль числа)
       dest = |source|. Доступен на SLC 5/03 и выше.

CPT  — Compute (Вычисление выражения)
       Выполняет произвольное математическое выражение.
       Поддерживает: +, -, *, /, **, SIN, COS, TAN, ASN, ACS, ATN,
       LN, LOG, SQR, ABS, FRD, TOD, DEG, RAD, TRN, NEG.
       Доступен на SLC 5/03 и выше.

SCP  — Scale with Parameters (Масштабирование с параметрами)
       Линейное масштабирование: dest = (input - input_min) × 
       (scaled_max - scaled_min) / (input_max - input_min) + scaled_min.
       Удобно для преобразования аналоговых сигналов. SLC 5/03+.

SCL  — Scale Data (Масштабирование данных)
       dest = (source × rate / 10000) + offset.
       Коэффициент rate задаётся как 1/10000 от множителя.
       Доступен на всех SLC 500.

RMP  — Ramp (Линейный нарастание)
       Изменяет выход линейно от текущего значения к целевому
       с заданной скоростью. Используется для плавных переходов.
       SLC 5/03 и выше.

SWP  — Swap (Перестановка байтов)
       Меняет местами старший и младший байты в каждом слове
       указанного массива. Используется для конвертации Endian.
       SLC 5/03 и выше.

XPY  — X to the Power of Y (Возведение в степень)
       dest = source_A ^ source_B. SLC 5/03+.
```

## ТРИГОНОМЕТРИЧЕСКИЕ ИНСТРУКЦИИ (SLC 5/03 и выше)

```
SIN  — Sine (Синус)
       dest = sin(source). Аргумент в радианах. Результат — REAL (F8:).

COS  — Cosine (Косинус)
       dest = cos(source). Аргумент в радианах.

TAN  — Tangent (Тангенс)
       dest = tan(source). Аргумент в радианах.

ASN  — Arc Sine (Арксинус)
       dest = arcsin(source). Результат в радианах. Вход: -1.0 ... 1.0.

ACS  — Arc Cosine (Арккосинус)
       dest = arccos(source). Результат в радианах. Вход: -1.0 ... 1.0.

ATN  — Arc Tangent (Арктангенс)
       dest = arctan(source). Результат в радианах.

LN   — Natural Log (Натуральный логарифм)
       dest = ln(source). Вход > 0.

LOG  — Log to Base 10 (Десятичный логарифм)
       dest = log10(source). Вход > 0.
```

## ИНСТРУКЦИИ ОБРАБОТКИ ДАННЫХ

```
TOD  — Convert to BCD (Преобразование в BCD)
       Конвертирует целое число (0..9999999) в двоично-десятичный код.
       Полный результат в math register S:13-S:14 (32 бита BCD).

FRD  — Convert from BCD (Преобразование из BCD)
       Конвертирует BCD-код обратно в целое число.
       Полный результат в math register S:13-S:14.

DEG  — Radians to Degrees (Радианы в градусы)
       dest = source × (180/π). SLC 5/03+.

RAD  — Degrees to Radians (Градусы в радианы)
       dest = source × (π/180). SLC 5/03+.

DCD  — Decode 4 to 1 of 16 (Декодирование 4 в 1-из-16)
       Устанавливает один бит в 16-битном слове на основании 4-битного входа.
       Если source = 5, то бит 5 в destination будет = 1, остальные = 0.

ENC  — Encode 1 of 16 to 4 (Кодирование 1-из-16 в 4)
       Обратная DCD: находит номер младшего установленного бита
       в 16-битном слове и записывает его (0..15) в destination.

MOV  — Move (Копирование значения)
       Копирует source в destination. Один элемент (16 бит integer или float).

MVM  — Masked Move (Копирование через маску)
       Копирует source в destination через маску. Биты, не выбранные маской,
       в destination не изменяются.

AND  — Bitwise AND (Побитовое И)
       dest = source_A AND source_B.

OR   — Bitwise OR (Побитовое ИЛИ)
       dest = source_A OR source_B.

XOR  — Exclusive OR (Побитовое исключающее ИЛИ)
       dest = source_A XOR source_B.

NOT  — Bitwise NOT (Побитовая инверсия)
       dest = NOT source. Инвертирует все 16 бит.

COP  — Copy File (Копирование файла/массива)
       Копирует блок из length элементов из source в destination.
       Работает с любыми типами файлов (N7:, T4:, F8: и др.).
       НЕ прерывается коммуникациями — безопасна для согласованности данных.

FLL  — Fill File (Заполнение массива)
       Заполняет массив destination значением source на length элементов.
```

## FIFO / LIFO (ОЧЕРЕДИ И СТЕКИ)

```
FFL  — FIFO Load (Загрузка в FIFO-очередь)
       Добавляет значение source в конец FIFO-буфера при переднем фронте.
       Управляющая структура R6:n отслеживает позицию и длину.
       Биты: .EN, .DN (полный), .EM (пустой).

FFU  — FIFO Unload (Выгрузка из FIFO-очереди)
       Извлекает первый элемент из FIFO и помещает в destination.
       Принцип «первый вошёл — первый вышел».

LFL  — LIFO Load (Загрузка в LIFO-стек)
       Добавляет значение source на вершину LIFO-стека.

LFU  — LIFO Unload (Выгрузка из LIFO-стека)
       Извлекает верхний элемент из LIFO в destination.
       Принцип «последний вошёл — первый вышел».
```

## СДВИГОВЫЕ РЕГИСТРЫ

```
BSL  — Bit Shift Left (Сдвиг бит влево)
       Сдвигает все биты массива на одну позицию влево по переднему фронту.
       Загружает source_bit в бит 0. Старший бит уходит в UL (unload bit).
       Управляющая структура R6:n, параметр Length определяет размер.

BSR  — Bit Shift Right (Сдвиг бит вправо)
       Сдвигает все биты массива на одну позицию вправо.
       Загружает source_bit в старший бит. Младший бит — в UL.
```

## СЕКВЕНСОРЫ

```
SQO  — Sequencer Output (Выход секвенсора)
       При каждом переходе условия из 0 в 1 переходит к следующей позиции
       в массиве и записывает значение через маску в destination.
       Используется для пошагового управления выходами (как барабанный контроллер).
       Управляющая структура R6:n. Биты: .EN, .DN (дошёл до конца), .FD.

SQC  — Sequencer Compare (Сравнение секвенсора)
       Сравнивает текущие входные данные с текущей позицией массива через маску.
       Устанавливает бит FD (found), если данные совпадают.

SQL  — Sequencer Load (Загрузка секвенсора)
       Загружает значение source в текущую позицию массива секвенсора.
       Продвигает позицию при каждом переходе условия.
```

## УПРАВЛЕНИЕ ПРОГРАММОЙ

```
JMP  — Jump to Label (Безусловный переход)
       Переходит к указанной метке LBL, пропуская все ранги между ними.
       При прыжке вперёд — пропущенные ранги не выполняются.
       При прыжке назад — повторное выполнение рангов (осторожно: watchdog).

LBL  — Label (Метка)
       Определяет целевую точку для JMP. Занимает первую позицию в ранге.
       Метка: целое число 0..999.

JSR  — Jump to Subroutine (Переход к подпрограмме)
       Вызывает указанный файл подпрограммы (File 3..255).
       SLC 5/03+: поддерживает передачу до 3 входных и 3 выходных параметров.
       Вложенность: до 8 уровней (SLC 5/02), до 16 уровней (SLC 5/03+).

SBR  — Subroutine (Начало подпрограммы)
       Помещается в первом ранге вызываемой рутины. Принимает входные параметры.
       SLC 5/03+: до 3 входных параметров.

RET  — Return (Возврат из подпрограммы)
       Завершает подпрограмму и возвращает управление в вызывающую рутину.
       SLC 5/03+: до 3 возвращаемых параметров.

MCR  — Master Control Reset (Сброс главного управления)
       Используется парами: первый MCR — начало зоны, второй — конец.
       Когда условие ранга с первым MCR ложно, все неретентивные выходы
       внутри зоны сбрасываются. Ретентивные (OTL) — не затрагиваются.

TND  — Temporary End (Временное завершение)
       Завершает текущий скан подпрограммы. При следующем скане выполнение
       начинается сначала. В главной программе — переход к обновлению I/O.

SUS  — Suspend (Приостановка)
       Переводит процессор в режим Suspend (Idle). Записывает ID-номер
       в слово S:7 статусного файла для диагностики. Используется для отладки.

IIM  — Immediate Input with Mask (Немедленный ввод с маской)
       Немедленно считывает входные данные из указанного слота, не дожидаясь
       конца скана. Маска определяет, какие биты обновляются. SLC 5/02+.

IOM  — Immediate Output with Mask (Немедленный вывод с маской)
       Немедленно записывает выходные данные в указанный слот, не дожидаясь
       конца скана. Маска определяет, какие биты обновляются. SLC 5/02+.

REF  — I/O Refresh (Обновление I/O)
       Обновляет все входы и выходы немедленно (полное обновление).
       SLC 5/02: обновляет все I/O. SLC 5/03+: обновляет I/O и обслуживает коммуникации.
```

## СПЕЦИАЛИЗИРОВАННЫЕ ИНСТРУКЦИИ

```
RHC  — Read High-Speed Clock (Чтение высокоскоростных часов)
       Считывает значение внутренних высокоскоростных часов процессора
       (разрешение 1 мкс) в указанный адрес. SLC 5/03+.
       Используется для точного измерения интервалов времени.

TDF  — Compute Time Difference (Вычисление разницы времени)
       Вычисляет разницу между двумя метками времени, полученными RHC.
       Результат — интервал в микросекундах. SLC 5/03+.

FBC  — File Bit Comparison (Побитовое сравнение файлов)
       Сравнивает два массива побитово и находит первый отличающийся бит.
       Режимы: All (все за один скан), Incremental (по одному за скан).

DDT  — Diagnostic Detect (Диагностическое обнаружение)
       Сравнивает два массива побитово через маску (reference).
       Находит различия (диагностика). Записывает результаты в массив result.

RPC  — Read Program Checksum (Чтение контрольной суммы программы)
       Считывает контрольную сумму указанного файла программы.
       Используется для обнаружения изменений в логике. SLC 5/03+.
```

## БЛОЧНЫЕ ПЕРЕДАЧИ (REMOTE I/O)

```
BTR  — Block Transfer Read (Блочное чтение)
       Читает до 64 слов данных от удалённого устройства через Remote I/O.
       Управляющая структура: 3 слова integer (N7: файл).
       Адрес файла: M1. Асинхронная операция — не блокирует скан.

BTW  — Block Transfer Write (Блочная запись)
       Записывает до 64 слов данных в удалённое устройство через Remote I/O.
       Адрес файла: M0. Управляющая структура: 3 слова integer.
```

## ПИД-РЕГУЛИРОВАНИЕ

```
PID  — Proportional Integral Derivative (ПИД-регулятор)
       ПИД-регулятор для замкнутых контуров управления.
       Управляющий блок: 23 слова в integer файле (N7: или PD).
       Параметры: Kc (коэффициент усиления), Ti (время интеграла),
       Td (время дифференциала), SP (уставка), PV (переменная процесса),
       CV (управляющий выход), feed forward/bias, deadband.
       Режимы: Auto/Manual, Timed/STI mode, E (ошибка)/PV (derivative action).
       Масштабирование уставки: SMAX, SMIN. Ограничение выхода: CVH, CVL.
       Период обновления задаётся в параметрах контроллера или STI.
```

## ASCII-ИНСТРУКЦИИ (SLC 5/03 и выше)

```
ABL  — ASCII Test Buffer for Line (Проверка строки в буфере)
       Проверяет, есть ли полная строка (с терминатором) во входном буфере
       последовательного порта. Устанавливает FD, если строка найдена.

ACB  — ASCII Chars in Buffer (Символы в буфере)
       Возвращает количество символов во входном буфере канала.
       Результат в элементе .POS управляющей структуры.

ACI  — ASCII String to Integer (Строка ASCII в целое число)
       Преобразует ASCII-строку (например "1234") в целое число.
       Вход: строковый файл (ST). Выход: integer.

AIC  — Integer to ASCII String (Целое число в строку ASCII)
       Преобразует целое число в ASCII-строку.
       Вход: integer. Выход: строковый файл (ST).

ACL  — ASCII Clear Buffer (Очистка буфера)
       Очищает входной и/или выходной буфер последовательного порта.
       Параметры позволяют выбрать, какой буфер очищать.

ACN  — String Concatenate (Конкатенация строк)
       Объединяет две ASCII-строки. Результат в destination.

AEX  — String Extract (Извлечение подстроки)
       Извлекает подстроку из строки по заданной позиции и длине.

AHL  — ASCII Handshake Lines (Линии квитирования)
       Читает и устанавливает линии управления модемом (DTR, RTS, CTS, DSR)
       через маски AND и OR.

ARD  — ASCII Read Characters (Чтение ASCII)
       Читает указанное количество символов из входного буфера порта.
       Асинхронная операция. Результат в строковом файле.

ARL  — ASCII Read Line (Чтение строки ASCII)
       Читает символы из буфера до терминатора (конца строки).
       Терминатор определяется настройками канала.

ASC  — String Search (Поиск подстроки)
       Ищет подстроку внутри строки. Возвращает позицию первого вхождения.

ASR  — ASCII String Compare (Сравнение строк)
       Сравнивает две ASCII-строки. Устанавливает FD при совпадении.

AWA  — ASCII Write Append (Запись с добавлением)
       Записывает строку в порт и добавляет символы завершения
       (CR, LF и т.д.) из настроек канала.

AWT  — ASCII Write (Запись ASCII)
       Записывает строку в порт без добавления символов завершения.
```

## КОММУНИКАЦИОННЫЕ ИНСТРУКЦИИ

```
MSG  — Message (Сообщение)
       Отправляет/принимает данные через DH-485, DH+, Ethernet или DF1.
       Поддерживает: чтение/запись к SLC, PLC-5, MicroLogix, Logix и др.
       Управляющая структура: integer файл (50+ слов для SLC 5/03+).
       Асинхронная: не блокирует скан. Биты: .EN, .DN, .ER, .ST.

SVC  — Service Communications (Обслуживание коммуникаций)
       Принудительно обслуживает коммуникационный канал (DH-485, DH+).
       Используется для ускорения обработки MSG в длинных программах.

CEM  — ControlNet Explicit Message (Явное сообщение ControlNet)
       Отправляет явное CIP-сообщение через ControlNet через сканер 1747-SCNR.
       SLC 5/03 и SLC 5/04.

DEM  — DeviceNet Explicit Message (Явное сообщение DeviceNet)
       Отправляет явное сообщение через DeviceNet через сканер 1747-SDN.

EEM  — EtherNet/IP Explicit Message (Явное сообщение Ethernet)
       Отправляет явное CIP-сообщение через Ethernet. Только SLC 5/05.
```

## ИНСТРУКЦИИ ПРЕРЫВАНИЙ

```
STD  — Selectable Timed Disable (Запрет прерывания по таймеру)
       Запрещает прерывание STI (Selectable Timed Interrupt) на время
       выполнения критической секции кода. Используется в паре с STE.

STE  — Selectable Timed Enable (Разрешение прерывания по таймеру)
       Восстанавливает возможность прерывания STI. Парная инструкция к STD.

STS  — Selectable Timed Start (Запуск таймерного прерывания)
       Программно изменяет параметры STI: файл подпрограммы и/или 
       интервал прерывания. SLC 5/03+.

IID  — I/O Interrupt Disable (Запрет прерывания I/O)
       Запрещает прерывание от модулей I/O. SLC 5/03+.

IIE  — I/O Interrupt Enable (Разрешение прерывания I/O)
       Восстанавливает прерывание от модулей I/O. SLC 5/03+.

RPI  — Reset Pending Interrupt (Сброс ожидающего прерывания)
       Сбрасывает ожидающее (pending) прерывание I/O, которое
       произошло во время запрета. SLC 5/03+.

INT  — Interrupt Subroutine (Подпрограмма прерывания)
       Обозначает подпрограмму как обработчик прерывания I/O.
       Помещается в первый ранг подпрограммы-обработчика.
```

## СТРУКТУРА ФАЙЛОВ ДАННЫХ SLC 500

```
Файл   | Тип        | Описание
-------|------------|--------------------------------------------------
O0:    | Output     | Выходные данные (привязаны к выходным модулям)
I1:    | Input      | Входные данные (привязаны к входным модулям)
S2:    | Status     | Статусный файл процессора (ошибки, режимы, часы)
B3:    | Bit        | Битовый файл (внутренние флаги и реле)
T4:    | Timer      | Файл таймеров (структуры: PRE, ACC, EN, TT, DN)
C5:    | Counter    | Файл счётчиков (структуры: PRE, ACC, CU, CD, DN, OV, UN)
R6:    | Control    | Управляющий файл (BSL, BSR, FFL, FFU, SQO, SQC, SQL)
N7:    | Integer    | Целочисленный файл (16-бит signed: -32768..32767)
F8:    | Float      | Файл с плавающей точкой (32-бит IEEE float)
9-255  | User       | Пользовательские файлы (любые типы: N, F, B, T, C, R, ST и др.)
ST     | String     | Строковый файл (82 символа макс.) — SLC 5/03+
```

## АДРЕСАЦИЯ SLC 500

```
Формат: [File Type][File Number]:[Element][.Field][/Bit]

Примеры:
  O:0/0         — выход слот 0, бит 0
  I:1/0         — вход слот 1, бит 0  
  B3:0/0        — битовый файл 3, слово 0, бит 0
  T4:0.ACC      — таймер 0, аккумулятор
  T4:0.PRE      — таймер 0, уставка
  T4:0/DN       — таймер 0, бит Done
  C5:0.ACC      — счётчик 0, аккумулятор
  N7:0          — integer файл 7, слово 0
  F8:0          — float файл 8, элемент 0
  R6:0.LEN      — управляющий файл, длина
  R6:0.POS      — управляющий файл, позиция
  S:1/15        — статус, слово 1, бит 15 (first pass bit)

Индексная адресация (SLC 5/02+):
  N7:[N7:0]     — адрес слова определяется значением N7:0

Косвенная адресация (SLC 5/03+):  
  N[N7:0]:0     — номер файла определяется значением N7:0
```
